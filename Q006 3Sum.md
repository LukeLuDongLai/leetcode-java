# Q006 3Sum

## Problem

Given an integer array `nums`, return all unique triplets `[a, b, c]` such that:

`a + b + c = 0`

The result must not contain duplicate triplets.

### Example

```text
Input:
[-1, 0, 1, 2, -1, -4]

Output:
[
  [-1, -1, 2],
  [-1, 0, 1]
]
```

---

## Pattern

Sort + Two Pointers / Reduce 3Sum to 2Sum

## Key Idea

Sort the array first.

Fix the first number:

`a = nums[i]`

Then the remaining problem becomes:

`b + c = -a`

Use two pointers on the right side of `i`:

- `left = i + 1`
- `right = nums.length - 1`

For:

`sum = a + nums[left] + nums[right]`

- `sum < 0` → move `left` right
- `sum > 0` → move `right` left
- `sum == 0` → record the triplet and skip duplicates

## Java

```java
public List<List<Integer>> threeSum(int[] nums) {
    Arrays.sort(nums);

    List<List<Integer>> result = new ArrayList<>();

    for (int i = 0; i < nums.length - 2; i++) {
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }

        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                result.add(List.of(
                    nums[i],
                    nums[left],
                    nums[right]
                ));

                int leftValue = nums[left];
                int rightValue = nums[right];

                while (left < right && nums[left] == leftValue) {
                    left++;
                }

                while (left < right && nums[right] == rightValue) {
                    right--;
                }

            } else if (sum < 0) {
                left++;
            } else {
                right--;
            }
        }
    }

    return result;
}
```

## Complexity

- Time: `O(n²)`
- Extra Space: `O(1)` excluding sorting internals and the output

Sorting takes:

`O(n log n)`

The outer loop fixes `a` in `O(n)`, and the two-pointer scan takes `O(n)` for each `a`.

Therefore:

`O(n log n + n²) = O(n²)`

## Why Two Pointers?

Key transformation:

`3Sum`  
→ fix one number `a`  
→ `b + c = -a`  
→ reduce to Two Sum on a sorted array  
→ use opposite-direction two pointers

After sorting:

- sum too small → move `left` right to increase the sum
- sum too large → move `right` left to decrease the sum

## Common Mistakes

- Return values, not indices.
- The result must not contain duplicate triplets.
- Duplicates must be handled for `i`, `left`, and `right`.
- Two pointers work because sorting gives a predictable ordering.
- Three nested loops are `O(n³)`; fixing one number plus two pointers reduces it to `O(n²)`.
